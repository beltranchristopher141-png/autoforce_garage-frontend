# Backend AutoForce
API Express y MySQL. Copia `.env.example` como `.env`, importa `../database/autoforce.sql`, ejecuta `npm install` y `npm run dev`.
Endpoints principales:
- `GET /api/health`
- `GET, POST /api/productos`
- `PUT, DELETE /api/productos/:id`
- `GET /api/servicios`
- `GET /api/pedidos`
- `POST /api/pedidos`
- `GET /api/pedidos/:id/detalle`
